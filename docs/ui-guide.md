# Tilemaxx UI guide

## Game workspace

Choose **1 player · Solo** in **New game** to practice on your own. Type your
rack, then use **Find moves** for suggestions or **Enter your play** to record
a word directly. Refill your rack after each turn. All unseen tiles are in the
bag. Game scores, turn review, and archived games show your own plays and
score. The game finishes when you play the last tile, or you can choose
**End game** under **Game options → Manage game**.

On narrow windows, the board and rack sit above Possible moves. Wider windows put the board and moves side by side. The sidebar opens over the game as a drawer until there is room to dock it. The side-by-side layout fills the available width and reclaims the sidebar’s space when it switches to a drawer or collapses.

| Name | Where to find it |
| --- | --- |
| **Sidebar** | The profile picker, game navigation, settings, UI guide, and keyboard shortcuts. Use the three-line **Open sidebar** button beside the page title or **Collapse sidebar** beside the Tilemaxx logo. |
| **New game** | Start a game from the sidebar while connected to the server. The **Opponent** field suggests names from the current profile’s games within the last two weeks, using each game’s end date if recorded and its start date otherwise. **Board layout** follows **Platform** and sets the board, rack size, and bonuses. For **Wordfeud** and classic **Lexulous**, **Language** sets the tile bag and letter values and suggests an installed **Word list**. Expand **Game details** to edit the start date and notes. |
| **Keyboard shortcuts** | Open the guide from the sidebar or press **?** outside text fields. **Alt / Option + B** opens or closes the board coordinate overlay. **Alt / Option + R** focuses the rack. **Alt / Option + U** undoes the last change and **Alt / Option + Y** redoes it. **Alt / Option + F** opens the game picker with its opponent filter focused, or focuses the filter in Archived games. |
| **Review changes** | The sidebar status for games with local and server versions. Hover or open it, then select a game to jump to its sync warning. |
| **Settings** | The gear below the saved-changes status, beside the version number. Choose **Light**, **Dark**, or **System** under **Appearance**. Under **Gameplay**, **Skip played tiles during board entry** is on by default. After you enter a letter, the cursor advances to the next empty square. Select a played tile directly to correct it. Control rack highlighting, animations, and automatic reloads when the server has a newer version. **Hardware info** shows the browser concurrency hint and the effective compute worker limit. Tilemaxx uses the browser hint by default. Enable **Limit compute workers to** and enter a maximum, which starts at 1. The setting applies to opponent reply histograms, automatic exact endgame lines, Solve endgame, board-based bingo odds, Optimal exchange, and policy timelines. These choices apply to this browser only. |
| **Available offline / Offline unavailable** | Above the sidebar saved-changes status. Shows whether this game’s word lists, app, and screenshot tools are stored on this device. **Available offline** is a plain status label. Select **Offline unavailable** to see what went wrong and retry. Reopening offline requires HTTPS or localhost. |
| **Update and reload** | When automatic updates are off, select the arrow beside the version number to load the newer build. If another Tilemaxx tab is open, close it and try again. |
| **Game header** | The platform and active word list appear under the game name. A red history icon marks games without a complete recorded move history, including in the **Game picker** and **Archived games**. The tracked score is centered, and Game options is on the right. An inward-pointing chevron beside the active player’s score shows whose turn comes next based on the latest recorded word. After a pass or exchange, the chevron updates when the next word is recorded. Open the name to use the **Game picker** and its opponent filter. Each game’s score in the picker shows yours first. New games appear above any manually ordered games. |
| **Game options** | The three-dot button at the right of the game header. **Board tools** contains **Import screenshot**, **Move history**, and **Board help**. **Game details** shows the date, board layout and size, word list selector, notes, and an edit button. Expand **Manage game** to end, duplicate, archive, reset, or delete a game. From an archived game, **Start new game** opens a blank board with the same opponent and settings and today’s date. **Restore game** restores the saved archived position. |
| **End game** | Record a final score or mark the game finished without a score. **Archive game** starts checked. **Deduct unplayed tiles** starts checked when deductions apply and is disabled otherwise. Clear **Archive game** to keep the game in **My games**, where **Undo** can resume it. |
| **Game board** | The editable letter and premium grid. Tapping a square or selecting it with **Alt / Option + B** uses the same direction check. Tilemaxx looks right and down within the number of rack tiles and checks the squares immediately left and above for word extensions. A direct connection or multiple reachable side connections outweigh a single side connection. Ties start across. Tap the same square again to turn. Hold a placed tile to toggle blank and keep the cursor where it is. In the coordinate overlay, type **H6** or **6H** to select the same square. Adjust a typed column with **← / →** or a typed row with **↑ / ↓**. **H1** selects row 1 immediately. Type a second digit to jump to **H10** or another valid two-digit row. With your rack entered, press **Enter** while typing on the board to find moves. The **board control strip** shows the selected square as **6H** for across or **H6** for down. It contains **Define**, Undo, and Redo on desktop and phones. While typing, press **Space** before a letter to enter a blank, **.** to skip a square, or **Delete** to erase a letter. |
| **Last play** | The lane above the board shows the latest recorded play, with **You** or **Opp**, the main word, total points, and position when available. Hover or tap to see the points for each word formed and any bingo bonus. |
| **Board help** | The premium-square legend and board-entry instructions. |
| **Word score badge** | The points that appear beside a board word when you hover over a tile. |
| **Definitions** | In an English or French game, hover over a move word for half a second on desktop or hold it on a phone. This works on suggestions, endgame lines, sample replies, setups, exchange examples, and the words in score breakdowns and game review. Choose **Define**, then select a highlighted tile in a word. The definition opens beside the tile on desktop and in a sheet on phones. On desktop, you can also right-click a placed tile. An intersection shows both **Across** and **Down**. |
| **Move preview** | Highlighted tiles show the previewed play on the main board and mini boards. Green marks your letters, red marks the opponent’s, and blue marks assigned blanks. In a narrow workspace, the **preview bar** shows the word, points, and **Play** button. Tap a move on a phone or right-click it on desktop to pin its preview. Tap or click outside the move and its preview controls to clear it. |
| **Your rack** | The tile editor below the board. After you play, the first empty slot is selected for the refill if tiles remain in the bag. **Shuffle rack** sits on the left. The pouch on the right estimates the tiles in the bag by subtracting a full opponent rack from the unseen tile count, down to zero. The pouch turns red when the tiles on the board and rack exceed the configured count for any letter or blank. Select it to see the excess in Unseen tiles. Drag a tile between its neighbors to insert it, or focus a tile and press **Shift + ← / →**. Rack marks follow their tiles. |
| **Rack tools** | Choose **Enter your play** to draft a word directly on the board. Use the same square, direction, and skip controls as for opponent entry. Tilemaxx uses rack letters first and fills any shortfall with blanks, shown in blue. If the rack still cannot supply a letter, the tile is outlined in amber and the board strip shows what is missing. Use **Fix rack** to correct the rack while keeping the draft, or choose **Record anyway** and confirm which tiles were left before drawing. **Play** or **Enter** records a complete play, and **Cancel** or **Escape** discards it. Use **Exclude tiles** to hold tiles back or **Require tiles** to use them in every suggested move. Long-press a tile or press **↓** on the keyboard to cycle through excluded, required, and unmarked. Playing clears both kinds of mark, and Undo restores them. When shown, the opponent rack shares a row with Rack tools. |
| **Optimal exchange** | The button centered below your rack compares swaps while tiles remain in the bag. It requires enough playable rack tiles for a bingo under the active rules: 7 in standard Scrabble and Lexulous (whose rack holds 8). Empty slots and held tiles do not count; blank tiles do. The first pass screens swaps on the current board. Up to 20 finalists are ranked on 256 shared reply scenarios using the same opponent model as Bingo Mercenary. **Keep your rack** shows bingo availability on the current board. **Simulate exchange** shows expected score, bingo chance, and sample plays on the current board, with the after-reply estimate from Optimal exchange when available. |
| **Opponent rack** | The inferred tiles centered directly below yours when the bag is empty. During move review in a narrow workspace, both racks stack vertically beside the board. |
| **Unseen tiles** | The expandable tile counts below the racks. Open them from the summary or the bag icon beside your rack. The counts include tiles in the bag and on other racks. |
| **Game scores** | The score tracking panel with totals, right-aligned opponent statistics, and a signed point difference centered beneath the scores. An inward-pointing chevron beside the active player’s total marks whose turn it is. A gold trophy marks the winner of a finished game. **Find moves** records a scoreable opponent play before showing suggestions. Overwrite a placed tile or erase and re-enter it to correct its letter or blank status and update the recorded score. Use **Space** before typing a blank. On the latest opponent play recorded by **Find moves**, an erase reopens the play until the original squares are filled again or you record a different placement. To add a missing tile, use **Edit last opponent move**. If you pass or exchange without searching, use **Record opponent move** before entering the next play whenever the two plays could read as one. |
| **Game finish** | The board overlay shows the adjusted final score when either player goes out in a tracked game. On a win, fireworks continue while the overlay is open. Select **Archive game** to save it to Archived games and stay on its board. Tap or click outside the result card, or press **Escape**, to dismiss it. Select the final score in a finished or archived game to replay it. |
| **Score by move** | The chart above **Tracked move history** plots cumulative points from the current scoring period in pairs. Hover, tap, or focus the chart and use the arrow keys to see both scores and the words played. If a pair has one recorded play, the other score stays flat. |
| **Tracked move history** | The scored turn list inside Game scores. Expand it and select a word to open **Turn review**. The **Review game** button above the history opens policy timelines and missed opportunities. All review analysis uses the game’s currently selected word list; recorded moves and scores stay unchanged. |
| **Policy timeline** | In **Review game**, select **Opponent plays** or **Your plays** and analyze that side’s recorded placements in chronological order. **Your plays** estimates fit from the opponent’s point of view using the board and your recorded placements. **Top 5 fit** shows how often the placement makes the scoring shortlist across racks that could supply the played tiles. **Random** shows the shortlist's share of legal placements. Highlights require at least 80% fit and at most 25% Random. Sampled turns check 95% bounds at 128, 256, 512, and 1,024 racks. Borderline marks turns where the bounds leave a highlight in question. Select a move to see each policy’s chance of choosing the exact placement on a rack that could supply the played tiles. Open **Raw policy estimates** to also factor in the chance of holding those tiles. |
| **Bingo trophy** | The gold highlight and trophy next to a bingo in the move list, analysis, or a recorded game. |
| **Move history** | The board and rack change log in **Game options**. Undo and Redo step through these changes. |

## Possible moves and analysis

| Name | Where to find it |
| --- | --- |
| **Possible moves** | The list starts with up to 100 moves in the current sort order. Scroll past move 100 and choose **Show all moves** to reveal the remaining matches. In the stacked layout, **Find moves** tucks the rack beside the board when suggestions are available. Select a tile in the side rack to return to editing below the board. The heading reads **Possible moves - Endgame** when the bag count is zero. Use **×** at the top right to dismiss the results and return to **Find moves**. |
| **Solve endgame** | Available in active and archived games whenever the current position has an empty bag, including after **Find moves**, when the button sits beside **Shortlist**. Either rack can be partial. The opponent plays next. The panel ranks up to five options by swing from your perspective, worst first. The swing column includes the ply count. Hover over a row with the mouse to preview the move on the board. Click, right-click, or tap a row to toggle its selection and open or close the optimal line in **Reply details**. |
| **Move filters** | The Shortlist and All moves switch, word search, and square filter above the results list. Select the active **All moves** or **Shortlist** button again to return to your playing style, even if you switched between the lists. With **No style**, selecting **Shortlist** again returns to **All moves**. |
| **Move list** | The sortable table of suggestions. A **move row** is one suggestion, and a **column header** controls sorting. Open **WORD** and choose **Word length** to put the longest completed words first, with higher points first at equal length. The small number at the upper left of each row is its position in the full list sorted by raw points. It stays fixed across other sorts and filters. PTS is the play’s score. The smaller number underneath is the gap from the best score available with all rack marks cleared. **Adj.** is the score minus the reply delta. The list sorts by adjusted points once the initial reply checks finish. Choose either order in the points header. It reads **ADJ. PTS** when sorting by adjusted points. **Playing style** samples suggestions from the moves a Casual, Word-List Learner, or Strong Club Player could spot. The row shows its sampled rank. Hover or select the points cell for the style breakdown. This browser remembers the style for each game. Choose **Bingo Mercenary** for current points and expected next-turn bingo points. Choose **Bingo Tactician** to also account for the opponent’s reply, ordinary follow-ups, and bingo lanes. Ordinary plays contribute 75% of their current score and immediate bingos contribute 100%. **Run Bingo Mercenary** and **Run Bingo Tactician** start an analysis for up to 10 seconds. The move and bingo counts use the same totals in No style and all playing styles. Once used in a game, the selected style starts automatically on new **Find moves** searches. **Run another 10 seconds** continues provisional results. Bingo Mercenary also checks **High-ceiling setups** after its sampled ranking is ready. **U** shows the simulated styles’ utility below the points and points gap. Hover or select the points cell for its utility breakdown and rank. **Swap** appears in the header when the selected style would exchange. It marks the tiles and opens **Simulate exchange**, with the style’s reason. **No style** clears the saved style. **All moves** opens the full list and keeps your playing style saved. [Playing styles](player-profiles.md). |
| **Playing style** | In solo games, choose **Greedy Bingo** for immediate and next-turn bingos, **Score Lookahead** for points now and expected points over your next two turns, or **Bingo & Triple Words** for immediate bingos, current points, next-turn bingo chance, and open triple-word lanes. Casual, Word-List Learner, and Strong Club Player also rank solo plays using your board and rack. In two-player games, select **Master** and choose **Run Master** to compare the leading scores and leaves through the opponent’s reply and your next turn. Open **Utility breakdown** on a move to see the estimate or the swing from a known-rack endgame. |
| **Run another 10 seconds** | Appears below the endgame status when any of the six automatic exact lines reaches a limit. Continues only unfinished lines, allowing up to ten more seconds per move and reusing retained search work. It remains available after further limits. Changing the position, reply settings, worker limit, or reloading releases unfinished search state. Exact line searches use at most two workers to bound retained memory. |
| **Calculation timing** | Select the time below the move list for a breakdown of the initial Find moves run, including individual exact endgame solves when available. The bars behind the numbers use total elapsed time as the full-width reference. |
| **Reply delta** | The move-list number showing the change in the opponent’s reply score against the reference move. A lower opponent reply is favorable. |
| **Estimated endgame swing** | The EST. SWING column when the bag is empty. The figure measures the change in your lead. A fast search considers four promising moves per turn, finishing moves, and passes, looking up to seven plays ahead. These selective results remain approximate. The top six estimates receive automatic exact searches, whose completed results replace the estimates. It may also name an opponent go-out threat. |
| **Reply details** | The box at the bottom of Possible moves headed **Reply after [move]**. With tiles in the bag, Tilemaxx automatically checks the top 20 moves by score plus up to two **Premium block** and two **Better leave** candidates. Use the chart icon in the reply column to **Check reply histogram** for another move. The details show the distribution, comparison, chance the reply outscores your play, and **Heatmap**. With an empty bag they show the opponent rack, immediate reply, score checkpoints, and the option to calculate the optimal endgame line when applicable. |
| **Reply settings** | The expandable bag count and endgame controls. It shows **Prior scoreless turns** for Scrabble and Words With Friends, **Prior consecutive passes** for Wordfeud and Lexulous, and **Opponent has a final turn** for Crossplay. |
| **Reply heatmap** | The board view of where strong replies land. Select a **hotspot** to see its change and sample replies. |
| **Reply risk** | The quick badge shows the score of an opened premium reply and the chance the opponent holds its tiles. Rare examples are muted. Strong red marks replies that are both likely and costly. Tap the badge for the example and its before-and-after scores. |
| **Bingo odds** | The draw and board-based odds in the move list, with controls to calculate the board-based chances. |
| **Move analysis** | The panel opened by **Analyze**. Pick **analysis candidates** and choose **Run analysis**. Use **Opponent model** to view predictions for a [playing style](player-profiles.md). With an empty bag, adjust the **Endgame budget** to give each exact search more work. |
| **Move comparison** | The metric table in Move analysis. The first candidate is the **reference move** for relative comparisons. |
| **Move analysis details** | The expandable card for an individual candidate beneath Move comparison. It can show example replies, endgame swing, and final score. |
| **Optimal endgame line** | The exact sequence of plays in Move analysis details or in Reply details after **Calculate optimal endgame line**. In Reply details, each turn shows its rack leave: cream tiles for you and blue tiles for the opponent. `(Goes out)` marks an emptied rack. Lines start with no turn selected. Select a turn to preview its board; select it again, tap or click elsewhere, or press Escape to clear the preview. |
| **Score breakdown** | The per-word and bonus scoring details for an individual play. |

## Move notation

Move locations encode direction: `8G` starts across at column G, row 8; `G8` starts down at the same square. Board squares keep their letter-first labels, such as `G8`.

In **Game scores → Tracked move history**, lowercase letters are blanks and parentheses group letters already on the board: `C(A)tS` places C, a blank T, and S around an existing A. Existing blanks stay lowercase inside parentheses. Other word displays keep their usual spelling and tile colors; bingo trophies remain visible. Recorded moves without enough saved placement information retain their recorded spelling.

## Other screens

| Name | Where to find it |
| --- | --- |
| **Archived games** | Saved games moved out of the active game list, with filters, tracked scores, and each game’s selected word list. The default sort shows the newest end dates first and uses the start date when no end date was recorded. |
| **Board studio** | The board template library. The **board editor** sets board size, premium squares, and tile counts. |
| **Screenshot import** | The dialog that reads a board from a picture. Open it from **Game options** or use the icon beside the entry hint under an empty board in the side-by-side layout. The **crop controls** set the grid bounds. **Premium review** checks special squares, including **Use opening play scores** when available. |
| **Word lists** | The dictionary manager in the sidebar. The Game header shows the selected dictionary, and the selector is in **Game options**. |
| **Word list checker** | Open it from the sidebar, choose an installed word list or open a local text file, and enter a word. **Check word** or **Enter** reports whether the word appears in that list. The checker starts with your game’s word list when available. Local files stay in the browser. |
| **Dictionary sources** | Open it from the workspace footer to see the Wiktionary definition credits and license. The headword in a definition tooltip links to its source entry. |

Green marks a favorable result or change for you. Red marks an unfavorable one. The comparison labels, signs, and lead or loss text carry the same meaning. Ties, reference values, and counts such as rack size and sample size use neutral styling. Gold marks bingos.
